Experiment 2

Make your own what-if experiment

Type a topic or a story from the newsletter. A small AI model drafts a set of sliders and calculated results for it. Then you play with the sliders, and no AI is involved in that part. It only works for topics that can be turned into numbers you can change.

Read this first

The AI model is a free, no-account service run by Pollinations (terms, privacy). Its documentation allows one free request at a time, at least 30 seconds apart per IP address, so there can be a wait. It is best effort and can fail or change. Your topic text is sent to it, so do not type anything private. It is for people 16 and older. Small models make mistakes: a generated experiment can have wrong formulas or made-up numbers, which is why every formula is shown. This is a learning toy, not advice.

What the page does with the model's reply: it must be plain data in a fixed format (sliders, switches, up to 4 calculated results with arithmetic formulas). The page checks every field, rejects anything else, and rejects formulas that give an unusable number at the slider ends. No code from the model is run, and nothing is fetched from addresses it names. This is how this version works, not a rule of what is possible.
