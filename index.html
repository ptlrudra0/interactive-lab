Experiment 1: What does MCP change?

MCP (Model Context Protocol) is a standard way for an AI app to discover and call tools on a server. Ask the same question twice: once with the model on its own, once with it connected to a real MCP server that offers four small tools. When tools are on, you can see each call the model made and what the server returned.

Technical note: the MCP server here is a real one built with the official MCP SDK, and the page talks to it with the SDK's MCP client. Both run inside your browser tab and are connected by the SDK's in-memory transport, not over the network. The AI model itself is a remote service. Real MCP messages (tools/list, tools/call) are exchanged and shown below.

Limits, honestly

The AI model is a free, no-account service run by Pollinations (terms, privacy). Its documentation says free requests are limited per IP address to one at a time, at least 30 seconds apart. So each answer can take a while, and a "with tools" question needs two or more model calls. When the free slot is not ready the page says so and waits; it never pays for anything. It is best effort with no uptime promise, so it may fail or change. Small models make mistakes, and that is part of what you are looking at. Your question is sent to Pollinations and the model providers it uses. Do not type anything private. Pollinations says its service is for people aged 16 and over. This page needs a reasonably recent browser (Safari 12 or newer).
