Experiment 1: What does MCP change?

MCP (Model Context Protocol) is a standard way for an AI app to discover and call tools on a server. Ask the same question twice: once with the model on its own, once with it connected to a real MCP server that offers four small tools. When tools are on, you can see each call the model made and what the server returned.

Technical note: in "with tools" mode this site's backend calls the same MCP handler in-process, using real MCP messages. The public URL further down is the same code, tested separately with the official SDK client. They are not two separate servers being compared.

Limits, honestly

This runs on a shared free daily allowance, so it can run out. If it does, the page tells you and comes back at 00:00 UTC (05:30 IST). To keep it fair there is also a limit of 4 questions a minute and 25 a day per visitor. Small models make mistakes, and that is part of what you are looking at. Questions are sent to the model provider to get an answer; do not type anything private.
